Beginner Install of Gentoo

Now, some might say that this guide does a small(massive) amount of cheating by installing exclusively inside of VirtualBox, and also using Binaries. Here's what you should need:

  • Reading Comprehension
  • VirtualBox installed
  • The Gentoo LiveGUI ISO (So you don't have a blank TTY)
  • At least 4 CPU Cores and 8 GB RAM allocated to the VM (We are taking shortcuts, but Gentoo would sure like the headroom)
  • Internet (We're downloading binaries)
  • Patience (Gentoo by default compiles from source, so it takes a while if you install that way)
  • Probably have read the Arch Install Guide, as though it's still less technical jargon, most explanation will be there.
